# **App Name**: ProFolio Blueprint

## Core Features:

- Static Content Display: Pre-rendered display of all personal information including hero section, about me, skills, projects, experience, achievements, and contact details from static JSON or Markdown files.
- Project Showcase & Client-side Filtering: Visually impressive project cards with dynamic links, tech stacks, and premium hover effects. Implement client-side filtering based on project categories or technologies.
- Interactive UI Elements: Implement essential client-side interactions such as a Dark/Light mode toggle, smooth scrolling for navigation, a sticky header, and dynamic scroll-reveal animations for sections.
- Fully Responsive Design: Ensure a seamless and optimized viewing experience across all devices, from mobile phones to large desktop screens, with adaptive layouts.
- Resume Management: Provide a link to download the resume and implement a modal for quick inline preview without leaving the page.
- Static Contact UI: A well-designed frontend contact form and display of contact information. (Note: Actual form submission functionality would require an external, client-side-compatible service not included in this static MVP).
- SEO & Performance Optimization: Implement meta tags, proper semantic HTML structure, and image optimization for fast loading, accessibility, and high search engine visibility.

## Style Guidelines:

- Dark Color Scheme Default: A deep, professional aesthetic anchored by a muted indigo. Primary actions and interactive elements use a vibrant, contrasting blue. For light mode, colors will adapt to maintain legibility and visual balance.
- Primary color (e.g., for accents, interactive elements, highlights): #524699 (HSL: 255, 55%, 40%)
- Background color (dark scheme default): #17151C (HSL: 255, 15%, 10%)
- Accent color (for secondary calls to action, important details): #447FF2 (HSL: 228, 75%, 55%)
- Headline font: 'Space Grotesk' (sans-serif) for a modern, technical, and bold presence, ideal for titles and key statements.
- Body text font: 'Inter' (sans-serif) for exceptional readability and a clean, objective feel across all content sections.
- Utilize a consistent set of minimal, high-quality SVG line icons or subtly filled icons to maintain a clean and modern aesthetic. Brand social media icons will adhere to brand guidelines.
- Implement a clean, spacious layout with ample whitespace, strategic use of card-based components for skills and projects, and a professional timeline layout for experience. Responsive design is paramount.
- Incorporate subtle, tasteful animations for smooth scrolling, sticky navigation, interactive hover effects on cards and buttons, and scroll-triggered reveals for content sections to enhance user engagement without distraction.
